# Product docs

Rules for the docs in `docs/product/`.

- Product docs are at the System level. They state the problem Lorebay
  solves, what it offers people and agents, and what it leaves out.
- How `lorebayd` is built belongs in [architecture](../architecture/), and
  behavior a caller observes belongs in [contracts](../contracts/). A product
  doc names those topics in a sentence and links to their doc.
- A feature Lorebay as a whole leaves out, such as notifications, is listed
  under Scope in [lorebay.md](lorebay.md).
