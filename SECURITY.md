# Security Policy

## Reporting a vulnerability

Report a vulnerability privately. Never put it in a public issue, pull
request or discussion.

- **Preferred:** GitHub's
  [private vulnerability reporting](https://github.com/lorebayai/lorebay/security/advisories/new).
- **Otherwise:** email [contact@lorebay.ai](mailto:contact@lorebay.ai).

Include the affected version or commit, the steps to reproduce, and the
impact you expect. We confirm that we received the report, keep you informed
while we fix it, and credit you in the published advisory unless you ask us
not to.

## Supported versions

Security fixes land on `main` and ship in the next release. Only the latest
release is supported.
