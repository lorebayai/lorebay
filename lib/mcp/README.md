# lorebay-lib-mcp

MCP tools, authorization challenge, and protected resource metadata for the library.

## Usage

Enable the same database feature as core. Mount the router returned by
`router` at the root of the product's origin.

Run `moon run lib/mcp:format lib/mcp:lint lib/mcp:build` from the workspace root.
